A ready-made solution for the pause menu and basic settings. Easily changed and scaled to suit your needs. 
Implemented functions:
- Pausing and unpausing
- Pause menu with options for changing and adding functions
- Algorithm for highlighting the selected button
- Algorithm for pressing a button
- Full gamepad control enabled
- Algorithm for changing the menu window
- Created windows for basic settings and volume settings
- Ability to save settings to a file and read them from a file
- Algorithm for translation 
- Language change function
- Adjust the vibration power of the gamepad
- Change full screen and windowed mode
- Changing window size
